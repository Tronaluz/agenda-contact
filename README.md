# Agenda de Contatos

Uma aplicação web simples para gerenciar seus contatos, permitindo adicionar e visualizar nomes e números de telefone.

## Descrição

Esta Agenda de Contatos é uma aplicação web desenvolvida com HTML, CSS e JavaScript que permite ao usuário criar uma lista de contatos com nomes e números de telefone. A interface é simples e intuitiva, com um design moderno e responsivo.

## Funcionalidades

- **Adicionar Contatos**: Formulário para inserir nome e telefone
- **Visualizar Contatos**: Tabela que exibe todos os contatos adicionados
- **Interface Responsiva**: Design adaptável a diferentes tamanhos de tela
- **Armazenamento Temporário**: Os contatos são armazenados durante a sessão do navegador

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Google Fonts (Roboto)

## Configuração & Instalação

1. Clone o repositório:
   ```
   git clone https://github.com/seuusuario/agenda-contatos.git
   ```
2. Abra o arquivo `index.html` no seu navegador para utilizar a aplicação.

## Como Usar

1. Preencha o campo "Nome" com o nome do contato
2. Preencha o campo "Telefone" com o número de telefone
3. Clique em "Adicionar" para inserir o contato na agenda
4. O contato aparecerá na tabela abaixo do formulário
